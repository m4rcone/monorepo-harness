# Specs de features

Um spec por feature que toque 3+ arquivos ou cuja decisão de design não caiba
numa frase. Para o resto, plan mode basta.

Fluxo: `/spec <descrição curta>` → entrevista via AskUserQuestion → spec
autocontido salvo aqui → **sessão nova** (`/clear`) para implementar,
referenciando o spec pelo caminho.

Specs são artefatos da feature: podem ser apagados ou arquivados após o merge.
